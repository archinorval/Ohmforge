# ngspice reference data

The `*.csv` files here are **data generated by ngspice**, used only as
reference values for `tests/ngspice_compare.rs`.

* Generator: `ngspice-41`, the conda-forge `ngspice-exe` package, run in
  batch mode by `scripts/gen-ngspice-golden.sh` on the development box.
* ngspice was run only as an **external program**. Ohmforge does not link,
  vendor, port or ship any ngspice code. ngspice is mostly BSD-licensed, but
  its tree contains one GPL file; running the binary separately keeps
  Ohmforge clear of it. Do not add ngspice as a dependency.
* Inputs: `tests/circuits/<name>.cir`, unchanged except that the script
  appends a `.control` block (`wrdata` of the vectors named on the
  `* compare:` line, with `numdgt=12`).
* Format: two `#` header lines (origin and column names), then
  comma-separated rows: scale (time, swept value, or unused for `.op`)
  followed by the compared vectors.

To regenerate after changing a circuit:

```sh
NGSPICE=/path/to/ngspice scripts/gen-ngspice-golden.sh
```
